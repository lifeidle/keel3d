## 1. 项目总结

### 1.1 产品定位
二战题材**低多边形军事 FPS**，纯 Web（无安装、点开即玩）：单人战役（任务制）+ 联机（合作 PvE / 猎杀 PvP，Host 权威 P2P）。视觉基因：低多边形方块士兵 + 夜战照明（探照灯/照明弹）+ 军事播报语音。

### 1.2 技术栈
| 层 | 技术 | 版本/说明 |
|---|---|---|
| 渲染 | Three.js（WebGL2） | **0.169**（新，WebGPU 路线可用） |
| 物理 | Rapier WASM | 0.14 **compat 版**（单线程，WASM 内联 base64） |
| 构建 | Vite + TS | manualChunks 已拆 three/rapier 缓存友好 |
| 联机 | WebRTC DataChannel ×2 | rel（事件）+ unrel（20Hz 快照）；信令 = Pages Functions + KV |
| 部署 | Cloudflare Pages | wrangler CLI 部署；yexi.org |
| 测试 | Playwright + 自研探针 | 单测 20/20、site-audit、`?debug=1` 游戏内探针、双页面联机 e2e |

### 1.3 功能完成度
| 模块 | 状态 | 备注 |
|---|---|---|
| FPS 核心（射击/换弹/ADS/医疗/补给） | ✅ 定型 | 三兵种武器（步枪/冲锋枪/狙击） |
| 士兵 | ✅ 定稿 | 方块人：头身连接、持枪小摆臂、遇敌抬枪瞄准、弹性步伐、待机呼吸；GLB 皮肤管线封存可切回 |
| 坦克 | ✅ 定稿 | 程序化 rig：可驾驶、炮塔/炮管独立、AI 车组 |
| 任务系统 | ✅ | 歼灭/撤离/强攻/夺旗（种子决定）+ 增援/绝望冲锋 |
| 联机 | ✅ 修复上线 | 五大根因修复（双信封/状态倒退/PvP 跌任务/幽灵未创建/种子失联），双端 e2e PASS |
| 质量体系 | ✅ | 每轮部署五关全绿；性能/像素自测工具链 |

### 1.4 资产与体积账（现状）
| 项 | 体积 | 评价 |
|---|---|---|
| 全站 dist | 38 MB | — |
| **音频** | **23 MB**（37 wav + 28 ogg 双份） | ⚠️ **最大包袱**——wav/ogg 双格式重复打包，首屏拖累 |
| JS bundle | 2.8 MB（three + rapier + app，已分 chunk） | 良好（rapier 含内联 WASM） |
| 模型 | 1.4 MB（3 个 GLB） | 良好 |
| 士兵网格 | 1209 tris/兵 | 极轻，可放大军规模 |

### 1.5 已有性能手段（不重复造轮子）
InstancedMesh（沙袋环）✓ ｜ 质量 3 档 + 帧率 <26 自动降档 ✓ ｜ PointLight 池 ✓ ｜ 曳光/弹壳池化 ✓ ｜ 材质共享零重编译 ✓ ｜ rAF try/catch 防冻结 ✓ ｜ 雾控视距随档位 ✓ ｜ 指针/像素比随档位封顶 ✓

### 1.6 已知边界（阶段 1 设计决定）
联机 8 人上限、无 TURN 中继（穿透失败给明确提示）、host 退出=解散、PvP 无 AI 敌人。

## 2. Track A：效率最大化（用最新技术）

### A1. 资产体积（P0，收益最大、风险最低）
| 动作 | 现状 → 目标 | 手段 |
|---|---|---|
| 音频去重 | 23 MB → **~6-8 MB** | 只发 ogg（Chrome/Edge/Firefox 全支持）+ m4a（Safari）；wav 仅作构建源不进 dist；加载策略改为「武器声即时，环境/语音懒加载」 |
| 模型压缩 | 评估 meshopt/Draco | soldier/rifle/tank 共 1.4MB，收益中等，优先级低 |
| 缓存策略 | 已哈希分 chunk | 静态资产 `immutable` 长缓存（Pages 默认），SW 预缓存核心 3 个 chunk（可选） |

### A2. 渲染主干（P0-P1）
| 动作 | 说明 | 预期 |
|---|---|---|
| **Instancing 全面铺开** | 沙袋环已做；植被/岩石/滩头障碍/弹坑全部 InstancedMesh + `matrixAutoUpdate=false` | 千级物件 = 个位数 draw call |
| **动态分辨率** | 帧率跌破阈值先降渲染分辨率（0.85×/0.7×）再降画质档——比换档平滑 | 波动场景不掉帧感 |
| 静态合批与剔除 | 静态物件 `matrixAutoUpdate=false`；雾联动脉冲裁剪（fogFarMul 已有） | CPU 每帧省矩阵更新 |
| 阴影纪律 | 仅主平行光投影；阴影相机贴动作区（已随档位）；低档关影 | 已有，落地新内容时对账 |
| 帧预算对账 | 每加一类物件记录 draw calls / tris / 帧时间（diag 面板已有，补自动化阈值） | 预算：**draw calls <150、tris <300k、60fps 满帧** |

### A3. 物理升级（P1，需要跨域隔离）
| 动作 | 说明 |
|---|---|
| **Rapier 多线程版** | `rapier3d-compat`（单线程内联）→ `@dimforge/rapier3d` + SharedArrayBuffer 多线程；需 COOP/COEP 响应头——`public/_headers` 加两行，**先在预览域名回归全部单机+联机 e2e 再上主线**（隔离头会影响第三方资源加载，当前无外部资源，风险可控） |
| WASM SIMD | 现代浏览器自动启用；构建时确认 SIMD 特性开启 |
| 兵力规模 | 多线程物理解锁「同时 30-40 具实体」而不掉帧（现 20+） |

### A4. 主线程与包体（P1-P2）
- 零分配纪律：热路径（AI/快照/动画）复用 scratch 向量/四元数（部分已有，逐段审计）
- 代码分割：联机模块（net/ghosts）与坦克模块 `dynamic import` 按需加载——首包再降 ~15%
- **WebGPU 渲染后端（P2 评估）**：three 0.169 已可跑 `WebGPURenderer`（TSL 材质）；策略=加一个「渲染后端探测」：支持 WebGPU 且首帧基准更优 → 走 WebGPU，否则回 WebGL2。**放在画面层稳定之后做**（后处理节点要用 TSL 重写，工作量集中）
- Worker 化（P2 备选）：AI 寻路/批量矩阵放 Web Worker + SharedArrayBuffer（多线程物理就绪后自然解锁）

### A5. 性能自动化回归（P0，保障上面所有动作不倒退）
- e2e 加帧率断言：本地跑 60s 战斗场景，平均帧时间 / P95 帧时间入阈值（超了直接 FAIL）
- draw call / tris 计数进 diag 探针 + e2e 输出

## 3. Track B：画面（枪战游戏感）

### B1. 氛围层（P0，当天见效）
- 白天模式整体降饱和灰雾（贴参考图滩头）：雾色 #a9b2b6 系、天光冷灰、地面沙土色
- 夜战保持「探照灯+照明弹」的明暗戏剧性（已有优势，微调色温统一）
- 太阳/月亮角度按地图种子微倾，制造长影

### B2. 后处理管线（P1，枪战感的分水岭）
`EffectComposer`（three/addons 自带，零新依赖）：
| 效果 | 用途 | 档位 |
|---|---|---|
| **Bloom** | 曳光/枪口焰/照明弹发光——夜战氛围核弹 | high 开 |
| **Vignette + 胶片颗粒** | 军旅质感、压暗四角聚焦枪口 | 全档 |
| **LUT 调色** | 一张贴图统一全站色偏（灰雾/夜战两套） | 全档 |
| SMAA/FXAA | 与 MSAA 二选一按档位 | med/low |
性能纪律：后处理只在 high/med 档；low 档直出；Bloom 半分辨率。

### B3. 特效升级（P1）
- 枪口焰**真实点光**（池化 PointLight，1 帧生命周期）——开枪照亮周围地面，枪战感立涨
- 曳光弹拖尾加宽/渐隐；弹着点火花+尘土粒子；爆炸冲击波环+烟柱
- 弹孔贴花池（墙面/沙袋）；尸体渐隐尘土
- 屏幕反馈：受击方向红晕已有 → 加 FOV 微震、枪口上跳

### B4. 武器手感（P1）
- viewmodel（第一人称枪模）：行走摆动、开火后坐位移、ADS 平滑过渡、换弹动作分节
- 枪口烟余韵、抛壳（池化刚体碎件）

### B5. 场景物件（P2，Instancing 主战场）
- 滩头：反坦克刺猬、龙牙桩、铁丝网（贴图 alpha）、沉船残骸
- 地堡/碉楼（可进入的 window 射击孔）、战壕段
- 建筑包替换方块房（已有 assets 建筑包）；弹坑（贴花+地形色斑）
- 植被：低多边形灌木/树（InstancedMesh，千级）

### B6. 角色细节（P2，保持方块人基因）
- 兵种盔差异（步枪兵 M1 / 冲锋枪兵船帽 / 狙击兵伪装网）、背包/水壶挂件盒
- 军衔臂章贴花、 allies 浅盔色已有 → 加发光小旗（联机识别）

### B7. 音频空间化（P1，沉浸短板补齐）
- 关键声源 3D 化：Web Audio `PannerNode`（方位+距离衰减）——敌人枪声/脚步/坦克引擎「听得出来方向」，枪战体验质变
- 已有 1250 音频库全复用，只是加声学摆放

### B8. HUD/战术地图（P2）
- 军用模板字体（stencil 风）、命中标记 X、击杀播报条打磨
- 全屏战术地图：等高线+任务标记动效

## 6. 风险与回滚
- **COOP/COEP 隔离头**：会影响一切第三方嵌入（当前无）——预览域名全量回归后再合主线；_headers 一行回滚
- **WebGPU**：只做「探测+更优才启用」，主路径永远 WebGL2 可回
- **多线程物理**：物理行为需回归（碰撞参数不变，API 迁移）；旧 compat 版保留分支
- **后处理**：档位开关独立，出问题整层关闭不影响玩法
